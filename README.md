# nagori

> 評価経済から距離をおき、AIではない生きたことば、感性を残していく。

`nagori` は、数字やいいねなどの評価システム、そして最適化された自動生成テキストから離れ、
ひとりの人間がその瞬間・その場所で抱いた「思考の痕跡」を静かに記録・交錯させるためのローカルファースト・プロジェクトです。

本リポジトリでは、約320バイトの軽量プロトコル仕様（`schemas/`）と、それを手元で動かすためのアプリ（`apps/`）を管理しています。

### コアコンセプト
- **生の感性の保持**: アルゴリズムに最適化された文章ではなく、手触りのある個人の言葉を残す。
- **脱・評価経済**: スコア、ランキング、フォロワー等の数字を徹底的に排除。
- **ローカルファースト ＆ 一期一会**: データは手元の端末が主権を持ち、中継データは風のように消える。
