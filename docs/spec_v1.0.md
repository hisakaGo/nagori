# SnowCrystal Code (SCC) 規格書ドラフト (v1.0)

## 1. 概要 (Overview)
SnowCrystal Code (SCC) は、雪の結晶が持つ6方放射の幾何学的美しさと、光学カメラ（スマートフォン等）による読み取り堅牢性を両立した2次元バイナリコード規格である。

中心角 30°（1/12ドメイン）の基本単位を鏡像反転および回転展開（万華鏡方式）させることで、全体として正十二角形（または十二条の星型）の結晶パターンを形成する。

---

## 2. 物理・幾何学構造 (Geometry & Grid Schema)

### 2.1 ドメイン構成
* **全周展開:** 360° を 12 分割した 中心角 30° の扇形（1/12ドメイン）を基本領域とする。
* **対照性展開:** 1/12ドメインを鏡像反転させた 60° の領域を単位とし、これを 6 回回転展開して全周を描画する。

### 2.2 セル（グリッド）定義
* **セル形状:** 角が 30° - 60° - 90° の直角三角形（正三角形を半分に割った形状）。
* **全セル構成:** すべてのセルは完全な**合同パーツ**であり、上下交互（▲・▼）に隙間なく噛み合って配置される。
* **階層構造:** 1/12ドメインは $N = 50$ 階層に分割される。
  * 階層 $n$ （$1 \le n \le 50$）に含まれるセル数: $2n - 1$ 個
  * 1/12ドメイン内の総セル数: $\sum_{n=1}^{50} (2n - 1) = 50^2 = 2,500$ 個

---

## 3. アライメント・領域定義 (Domain Allocation)

2,500個のセル領域は、機能ごとに以下の3つの領域に区分される。

| 領域 | 該当階層 | セル数 | 描画値 | 機能・目的 |
| :--- | :--- | :--- | :--- | :--- |
| **中心空き領域** | 第 1 〜 9 階層 | $9^2 = 81$ | 0（黒/背景） | 背景色領域。アライメントマークのコントラスト確保。 |
| **アライメント枠** | 第 10 階層 | $10^2 - 9^2 = 19$ | 1（白/固定） | 全周展開時に中心に太い枠線を形成し、中心点および角度を検出。 |
| **データ領域** | 第 11 〜 50 階層 | $50^2 - 10^2 = 2,400$ | 動的（データ）| 1セル = 1ビットとしてデータを格納。 |

※ 描画色定義: `1` = 白（結晶の枝） / `0` = 黒（背景）

---

## 4. データマッピング・ビット配置 (Data Mapping Schema)

データ領域（2,400ビット / 300バイト）は、カメラの光学解像度特性に基づき、外周から内側へ向かって**外周優先らせん走査**で割り当てられる。

### 4.1 アドレス割り当て順序
1. **階層走査 ($n$):** 第 50 層（最外周）から第 11 層（最内周）へデクリメント。
2. **層内走査 ($k$):** 各層内において、中心軸（0°線）側から外縁（30°線）側へ $k = 0 \dots 2n-2$ の順で配置。

### 4.2 ビット構造レイアウト

[Bit 0] (第50層・最外周)                                            [Bit 2399] (第11層・最内周)
|--- Header (99bit) ---|------------ Payload (1,821bit) ------------|--- RS-ECC (480bit) ---|


* **Header (Bit 0 〜 98 / 99 bit):** バージョン、データ長、メタデータ。最も解像度の高い第50層に配置。
* **Payload (Bit 99 〜 1919 / 1,821 bit):** メインデータ本体（約227.6バイト）。
* **RS-ECC (Bit 1920 〜 2399 / 480 bit):** リード・ソロモン誤り訂正符号（60バイト）。光学ボケ・歪みで潰れやすい第11〜20層へ集中的に配置。

## 5. 結晶生成マスク (Snowflake Masking Schema)

データのランダムパターンによる外観の破綻を防ぎ、美しく「雪の結晶の枝伸び」を再現するため、生データビット列に排他的論理和（XOR）マスクを被せる。

### 5.1 マスク演算
* **エンコード:** $B_{\text{draw}}(n, k) = B_{\text{data}}(n, k) \oplus M(n, k)$
* **デコード:** $B_{\text{data}}(n, k) = B_{\text{draw}}(n, k) \oplus M(n, k)$

### 5.2 マスクパターン関数 $M(n, k)$
層内セル $k$ の中心軸（0°線）からの角度離れ度合いに応じた確率分布関数、または以下に示す決定論的幾何関数により生成する。

$$M(n, k) = \begin{cases} 1 & \text{if } (k \bmod 4 \le 1) \text{ or } (\text{中心軸近接条件を満たす}) \\ 0 & \text{otherwise} \end{cases}$$

これにより、中心軸（正三角形の高さにあたる辺）周辺に「白（1）」が集中的に配置され、中心から放射状に伸びる主枝および横枝の骨格が自動形成される。

## 6. デコード・画像処理規定 (Decoding Process)

1. **アライメント検出:**
   画像から二値化処理を行い、第10層が形成する中心の十二角形リング（アライメントパターン）を検出。中心座標 $(X_0, Y_0)$ および回転角 $\Phi$ を特定する。
2. **射影変換 (Perspective Transform):**
   検出した十二角形および最外周（第50層）の輪郭をもとに、歪みを正十二角形キャンバスへ補正。
3. **サンプリング:**
   1/12ドメイン内の各直角三角形セルの**内心（Centroid）の輝度平均**を取得し、閾値処理により `0` または `1` を判定。
4. **アンマスク & ECC復元:**
   サンプリングデータにマスク $M(n, k)$ を XOR 演算して生ビット列を復元後、Bit 1920〜2399 の RS パリティを用いて失われたビット（特に中心付近の低解像度領域）を数学的に完全修復する。
