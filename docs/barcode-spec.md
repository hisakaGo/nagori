# nagori 独自2次元バーコード仕様書 (SnowCrystal Code / 仮称)

> 中心に雪の結晶を戴き、正三角形のメッシュで言葉の痕跡を刻む2次元コード設計。

`nagori` プロトコルでは、標準的なQRコードが持つ工業的・不規則な外観（四隅のファインダーパターン等）を廃し、思想的・視覚的に美しい独自の2次元バーコード **「SnowCrystal Code（仮称）」** を採用します。

---

## 1. 核心デザイン思想

1. **手触りと情緒の復権**
   無機質な四角いグリッドではなく、正三角形メッシュ（三角格子）によって生み出される六角形・6軸放射状の幾何学パターンを採用します。
2. **中心の雪の結晶（アンカー）**
   「舞い降りて静かに漂い、やがて消えていく」という `snap` の思想を象徴する**雪の結晶**を中心に配置し、位置検出および回転角検出のメイン原点とします。
3. **脱・四角形**
   QRコード特有の四隅の黒い二重正方形を完全に排除し、中心の結晶から外側へと言葉が結晶化して広がる点対称的なグラフィックを形成します。
