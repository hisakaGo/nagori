# nagori 独自2次元バーコード仕様書 (SnowCrystal Code / BARCODE_SPEC.md)

> 中心から幾何学が広がり、言葉の痕跡を雪の結晶として刻む2次元コード設計。

`nagori` プロトコルでは、標準的なQRコードが持つ工業的・不規則な外観（四隅の切り出しシンボル等）を廃し、美しく洗練された独自の2次元バーコード **「SnowCrystal Code (SCC)」** を採用します。

---

## 1. 核心デザイン思想

1. **手触りと情緒の復権**
   無機質な四角いグリッドではなく、30°-60°-90° の直角三角形セル（正三角形の半角）を密に噛み合わせた万華鏡（カレイドスコープ）幾何学構造を採用。幾何学的な均整と有機的な「雪の結晶」の意匠を両立します。
2. **中心のアライメントリングと幾何学的原点**
   「舞い降りて静かに漂い、やがて消えていく」という `snap` の思想を象徴する中心部に、第10階層の正十二角形リング（アライメント枠）を配置。カメラ画像解析における位置検出および回転角検出の確実なメイン原点とします。
3. **脱・四角形・12方放射グラフィック**
   QRコード特有の四隅のファインダーパターンを完全に排除。1/12ドメイン（30°扇形）のデータ領域を鏡像反転および回転展開させることで、中心から結晶が外側へ美しく伸びていく点対称的なグラフィックを形成します。
